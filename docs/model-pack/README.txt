Bibi AI model pack (closed test)

These files let the Bibi AI app run fully on your phone. The app checks every file's size and fingerprint before using it.

Files
- gemma3-1b-it-int4.litertlm (585 MB). Needed: Bibi's chat model, Google's Gemma 3 1B.
- embeddinggemma-2-text-270m.litertlm (165 MB). Optional: lets Bibi understand phone requests like "wake me up at seven". Also a Gemma model.
- bibi-voice (folder, about 730 MB). Optional: talking to Bibi. It holds parakeet-tdt-0.6b-v2-int8 (NVIDIA Parakeet, CC BY 4.0) and piper-en_US-amy-low (Piper "amy" voice, CC BY-SA 4.0).
- NOTICE.txt and Gemma-Terms-of-Use.pdf: the Gemma terms.
